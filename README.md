# Confinement ingredient guide

A bilingual visual shopping guide with 73 ingredient photographs, English and Chinese names, Cantonese pronunciation, and shopping quantities.

Static HTML, CSS and JavaScript. No login or build step required.

Enable GitHub Pages in Settings → Pages, choose Deploy from a branch, then main and / (root).

Photos are visual references only. Confirm uncertain unlabeled herbs before use. Photo source links are included in the guide; original photos were supplied in the existing guide. Third-party photographs retain their respective rights.
